4- Nuestro Proyecto Arduino, "Titulo Proyecto" se basa en un peaje de barrera que otorga acceso a un estacionamiento. 
El sistema identifica la proximidad de un objeto, en este caso un auto de coleccion HotWheels, para que una vez cerca de la Barrera, le pida al conductor un codigo de acceso único que introduce por un KeyPad. Si el codigo introducido es correcto, abre la barrera. En caso contrario la barrera se matiene cerrada pidiendole que ingrese nuevamente el código. El usuario será informado mediante una pantalla oled los estados de los intentos de acceso. Luego que el auto pase, la barrera baja y comienza el ciclo nuevamente.
